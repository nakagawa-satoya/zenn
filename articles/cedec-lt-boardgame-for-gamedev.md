# ゲーム開発者にこそ勧めたいボードゲーム制作

:::message
この記事は、CEDEC Lightning 2026 で発表予定のライトニングトーク（5分）の内容をまとめたものです。
:::

## はじめに

ゲーム開発者の皆さん、**最後に自分の企画を「完成」させたのはいつですか？**

デジタルゲーム開発の現場では、開発サイクルの長期化が深刻な課題になっています。AAAタイトルでは5〜7年、場合によっては10年を超えるプロジェクトも珍しくありません。その結果、企画から製造、販売、ユーザーフィードバックまでの **商品開発サイクル全体を一人で体験する機会** がほとんどなくなっています。

本セッションでは、その課題を解決する手段として **ボードゲーム制作** を提案します。

## ゲーム業界が抱える「長すぎる開発サイクル」問題

### デジタルゲームの開発期間

| 規模 | 平均開発期間 |
|------|-------------|
| AAAタイトル | **5〜7年**（10年超の事例も） |
| コンシューマー（中規模） | 2〜3年 |
| モバイルゲーム | 1〜2年 |
| インディーゲーム（個人） | 1〜3年 |

> AAAタイトルの開発期間は年々長期化しており、数年から10年近くに及ぶケースもあります。
> 参考: [ゲームの開発期間はどれぐらい？](https://game-creators.jp/media/career/999/)

### 長期化がもたらす問題

1. **経験の分断** — 一人の開発者がプロジェクトの全フェーズを経験できない
2. **フィードバックの遅延** — ユーザーの反応を見るまでに何年もかかる
3. **学習サイクルの停滞** — 「作って、出して、反応を見て、改善する」を回せない
4. **キャリアの硬直化** — 特定の工程だけを担当し続けることでスキルが偏る

> ゲームの数が増え、大企業が保守的になる中、開発者はいかにしてキャリアを築くべきか？
> 参考: [CEDEC 2024 セッションレポート（4Gamer）](https://www.4gamer.net/games/999/G999905/20240830016/)

## ボードゲーム制作は「商品開発の全体験」ができる

### ボードゲームの開発サイクル

ボードゲーム制作は **短期間で商品開発の全工程を体験** できます。

```
企画（1〜2週間）
  ↓
プロトタイプ制作（数日〜数週間）
  ↓
テストプレイ・改善（1〜3ヶ月）
  ↓
アートワーク・デザイン（1〜2ヶ月）
  ↓
製造（1〜2ヶ月）
  ↓
販売・マーケティング（イベント当日）
  ↓
ユーザーフィードバック（即日〜）
```

**デジタルゲームで5年かかるサイクルを、3〜6ヶ月で回せます。**

### 一人で学べる全領域

ボードゲーム制作では、商品開発に必要なスキルを **ワンストップで** 学べます。

| フェーズ | 学べること | デジタルゲーム開発との対応 |
|---------|-----------|------------------------|
| **企画** | コンセプト設計、ターゲット選定 | ゲームデザイン |
| **制作** | メカニクス設計、バランス調整 | ゲームプログラミング |
| **テストプレイ** | ユーザビリティ検証、行動観察 | QA・UXリサーチ |
| **製造** | 入稿、原価計算、在庫管理 | パブリッシング |
| **販売** | 価格設定、POP制作、接客 | マーケティング |
| **マーケ** | SNS告知、レビュー依頼、動画 | コミュニティマネジメント |

## 同人から世界へ — 代表的なサークルと作品

「個人で作ったボードゲームがどこまでいけるのか？」。答えは **世界** です。

### ゲームマーケット大賞 歴代受賞作

ゲームマーケット大賞は2014年に創設された、会場での投票で選出される賞です。すべて **個人・サークル発の同人ゲーム** から生まれました。

| 2016 | **ビンジョー×コウジョー** | ワーカープレイスメント |
| 2017 | **8ビットモックアップ** | タイル配置パズル |
| 2018 | **天下鳴動** | ダイス×陣取り |
| 2019 | **FOGSITE** | 非対称チーム戦・迷路探索 |

> 参考: [過去全5回のゲームマーケット大賞受賞作を一挙紹介](https://kujiraction.com/1940/)

### 注目すべきサークル・作品

#### カナイ製作所 —『ラブレター』

カナイセイジ氏が **2012年のゲームマーケットで500円で販売** した同人ゲーム『ラブレター』は、たった16枚のカードで遊べるシンプルなゲームながら、世界的な大ヒットとなりました。

- **ドイツゲーム大賞2014** で日本人初の4位入賞
- アメリカの出版社AEGから海外版が発売
- 全世界シリーズ累計 **300万部突破**（2022年時点）

> 500円の同人ゲームが世界300万部。これが個人制作の可能性です。
> 参考: [『ラブレター』は"たまたまできた運の産物"!?（BROAD）](https://broad.tokyo/interview/27638)

#### OKAZU brand —『Trains（トレインズ）』

2007年から活動するOKAZU brandは、ゲームマーケットに毎回新作を持って参加。代表作『Trains』は **Origins Award 2014 Best Board Game** を受賞し、国際的な評価を得ました。ドイツ・エッセンの世界最大規模のボードゲームイベントSPIELにも毎年参加しています。

> 参考: [OKAZU brand（ゲームマーケット公式）](https://gamemarket.jp/booth/1059)

#### ClaGla（クラグラ）—『たった今考えたプロポーズの言葉を君に捧ぐよ。』

ゲーム創作グループCRIMAGEが **ゲームマーケット2017秋で頒布開始** した大喜利系ゲーム。SNSで大きな話題となり、法人化（株式会社ClaGla）を経て、シリーズ累計 **35万部超** を突破。

> 同人即売会から法人設立・量産展開へ。商品開発のリアルを体験できる好例です。
> 参考: [ClaGla公式 — たった今考えたプロポーズの言葉を君に捧ぐよ。シリーズ](https://www.clagla.jp/propose-series.html)

### 共通するポイント

これらの成功事例に共通するのは:

1. **ゲームマーケットで同人として頒布開始** した
2. **テストプレイを重ねてゲーム性を磨いた**
3. **短期間の制作サイクル** でリリースまで到達した
4. ユーザーの反応を受けて **改善・拡張・商業化** に至った

ゲーム開発者が日常的に求められるスキル — 企画力、調整力、マーケティング感覚 — を **すべて実践で学べる** のがボードゲーム制作です。

## テストプレイ = 最速のユーザーフィードバック

ボードゲーム制作における最大の強みは **テストプレイの即時性** です。

### デジタルゲームとの比較

| | デジタルゲーム | ボードゲーム |
|---|---|---|
| プロトタイプ制作 | 数週間〜数ヶ月 | **数時間〜数日** |
| テスト実施 | テスト環境構築が必要 | **紙とペンがあれば即実施** |
| フィードバック取得 | リリース後 or クローズドβ | **目の前で行動を観察** |
| 改善の反映 | ビルド・デプロイが必要 | **その場でルール変更可能** |
| イテレーション速度 | 週〜月単位 | **日単位** |

### テストプレイの実践ポイント

ゲームデザイナーの米光一成氏は、テストプレイにおいて **「説明してはいけない」** と述べています。

> ポンとゲームだけを手渡して、行動を観察するのが重要。
> 参考: [テストプレイは行動の観察が重要（米光一成）](https://note.com/yonemitsu/n/nec445c5cc06e)

これはまさにUXリサーチの手法そのものであり、デジタルゲームのユーザビリティテストにも直接応用できるスキルです。

テストプレイ会やゲームマーケットの **試遊スペース** では、見知らぬ人に遊んでもらい、リアルタイムにフィードバックを得ることができます。こうした体験は、通常の業務ではなかなか得られません。

## 制作コストは驚くほど低い

## 明日からできるアクション

1. **まずは遊ぶ** — ボードゲームカフェやゲームマーケットに足を運ぶ
2. **紙で作る** — 思いついたメカニクスを紙とペンでプロトタイプ化
3. **遊んでもらう** — 同僚や友人にテストプレイしてもらい行動を観察
4. **イベントに出す** — ゲームマーケットに出展して「商品」として世に出す

**開発サイクルが長いからこそ、短いサイクルで「作る→出す→学ぶ」を回す経験が、あなたのゲーム開発者としての力を加速させます。**
